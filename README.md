# 3laa Shelkamy — Portfolio

A lightweight bilingual (English / Arabic) portfolio for GitHub Pages.

## Deploy
1. Upload `index.html` and the `assets` folder to the root of your GitHub repository.
2. In Settings → Pages, select Deploy from a branch → `main` → `/(root)` and Save.
3. Wait for GitHub Pages to publish your site.

## Customize before sharing
- Replace the four project placeholders with your actual videos and covers.
- Replace the generic Instagram URL in `index.html` with your real profile.
- Replace the hero image at `assets/portrait.webp` if desired.
- Do not add unverified client logos or performance claims.
